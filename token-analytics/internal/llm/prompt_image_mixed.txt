	•	Token Ticker: {{((.Ticker))}}

	1.	Post text
		•	Defines the idea, emotion, tone, or punchline
	2.	Optional media
		•	Used only to reinforce mood or symbolism
		•	Must be ignored if it conflicts with the text
		•	Must never introduce a new concept not present in text

⸻

	1.	Extract the core idea or emotion from the text
	2.	Reduce it to a single visual symbol or character

		•	reinforce confidence or irony

	•	the idea is clearly humorous, absurd, or expressive
